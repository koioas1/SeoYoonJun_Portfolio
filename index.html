About this designer

시스템 기획자 서윤준입니다. 재미있는 게임은 결국 좋은 시스템 설계 위에서 완성된다고 생각합니다.
PathTowerDefence 에서는 매 게임마다 무작위로 생성되는 적의 경로 위에 8칸 인벤토리, 타워 업그레이드, 경로 설계를 얹어
한 번의 타워 배치가 한 라운드의 전략이 되도록 설계했습니다.
Donut Crash 에서는 전투 흐름을 5단계 프로세스로 정의하고 그 위에 12개 도넛 스킬과 7개 마녀 패시브를
같은 포맷으로 정리해 확장과 밸런싱이 용이한 구조로 만드는데 집중했습니다.

이전 직무에서 4년간 회계, 경영관리 실무를 경험하며 수치와 데이터의 흐름을 검증하는 업무를 수행하였고
그 과정에서 예외 상황과 누락 가능성을 점검하는 습관을 길렀습니다.
현재는 그 경험을 바탕으로 구현 단계에서 개발자가 바로 작업 가능한 형태의 시스템 문서를 만드는 기획자를 목표로 하고 있습니다.

PathTowerDefence

타워디펜스 · 전략게임 · PC · 1인개발 · 2025

매 게임마다 무작위로 생성되는 적의 경로를 막아내는 1인 개발 타워디펜스 게임입니다.
기존 타워디펜스의 정해진 경로, 고정 배치 대신 절차적 경로 설계 시스템을 도입하여
플레이어가 직접 경로를 유도하되 "절대 차단 불가" 제약을 두어,
매 게임마다 다른 플레이 경험을 느낄 수 있도록 핵심 루프를 만들었습니다.

기획·시스템 설계·구현·테스트를 모두 단독으로 진행하며 컨셉부터 빌드까지의 전 과정을 경험했습니다.
절차적 경로 설계 시스템의 제약으로 "절대 차단 불가"를 두었고,
8칸 인벤토리, 상점에 무작위로 보충되는 기물의 메타 루프로 매 게임마다 다른 전략이 강제되도록 시스템을 짰습니다.

4종족 각각의 고유한 공격 특성, 4가지 적 각각의 고유한 특성을 적용한 뒤,
엑셀 시뮬레이션으로 DPS, 체력 곡선을 사전 검증한 뒤 시스템에 반영하였습니다.

Design Highlights
절차적 맵 생성 경로 유도 규칙 8칸 인벤토리 루프 3개 합성 업그레이드 무작위 상점 메타 4종족 시너지 웨이브 밸런스 곡선 절대 차단 불가 규칙 1인 개발

Donut Crash

턴제 배틀 게임 · Mobile · 팀 프로젝트 · 캐주얼 · 2025

5장의 도넛 덱을 구성하여 턴제 전투를 진행하는 물리 충돌 PvP 게임입니다.
10인 팀(기획4, 개발6)로 진행된 프로젝트이고 인게임 시스템 기획 전반을 담당하며 전투, UI, 밸런스, QA 프로세스를 모두 관리했습니다.
턴제 전투의 흐름을 5단계 상태 머신 구조로 정의하고, 속도 값을 활용한 충돌 기반 데미지 계산식을 설계하였으며
전투 상황에 따라 전략적 변수와 결과가 발생하도록 설계하였습니다.

전투 HUD, 스킬 발동, UI 팝업 구조 등 플레이 흐름에 필요한 인터페이스를 기획했으며,
Figma 프로토타입을 통해 실제 사용 흐름과 정보 전달 구조를 사전에 검증했습니다.
또한 Excel 기반 전투 시뮬레이터와 플레이 테스트를 통해 스킬 수치와 전투 밸런스를 반복적으로 조정했습니다.

개발 과정에서 버그 재현 및 우선순위 분류, QA문서화 작업과 개발 전달 프로세스를 담당했으며,
매일 오전 스크럼을 통해 개발 진척도와 일정 우선순위를 공유하였습니다.
특히 인게임 담당 개발자들과 지속적인 커뮤니케이션을 통해 구현 이슈와 충돌을 빠르게 조율하여 협업하였습니다.

5단계 배틀 페이즈 상태 머신 정의 12개 도넛 스킬 명세 7개 마녀 패시브 통일 명세 포맷 데이터 테이블 구조화 데미지 계산식 속도 정규화 SPD 크리티컬 시스템 인게임 UI 흐름 팝업 안전장치 예외처리 표준화

생쥐 대탈출!

방치형 클리커 · Mobile · 팀 프로젝트 · 2025

모바일 환경을 기반으로 제작중인 방치형 클리커 게임입니다.
기획 1인(본인) · 개발 1인의 체제의 2인 팀으로 진행중이며 메인 페이지 한 화면에 9개의 팝업이 연결되도록 설계했고,
각 팝업의 활성화 조건·내부 구조·확장성을 픽셀 단위로 명세했습니다.

방치형 게임의 핵심은 "플레이하지 않는 시간에도 자산이 늘어나는 즐거움"이라고 정의했습니다.
이를 위해 1초마다 발동하는 자동 생산 로직, 터치 수익에 0.05초 쿨타임 안전장치, 앱 강제 종료 시 자동 저장,
재접속 시 오프라인 수익 계산까지 계산하는 시스템을 설계하였습니다.

장기 플레이가 가능하도록 재화의 생성·소모 구조를 연구소 트리와 기념품 수집으로 다각화하고,
적절한 시점에 발생하는 성장 둔화 구간을 광고 시청 보상과 결합해 자연스러운 수익 모델을 구축할 예정입니다.

Design Highlights
UI 흐름도 설계 9개 팝업 명세 픽셀 단위 좌표 정의 방치형 생산 로직 오프라인 수익 계산 재화 경제 구조 연구소 성장 트리 기념품 수집 루프 광고 보상 모델 자동 저장 시스템 입력 안전장치
